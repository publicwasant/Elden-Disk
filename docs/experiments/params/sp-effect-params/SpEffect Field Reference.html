SpEffect Field Reference

SpEffectParam: ทุกฟิลด์

ตาราง effect ของ Elden Ring 1.17.1 ทั้ง 370 ฟิลด์ ค่าในคอลัมน์ขวาเป็นค่าจริงของแถว 1621000 (Black Flame, ตัวเผา DoT) เทียบกับค่าที่พบบ่อยที่สุดในทุกแถว กดชื่อฟิลด์เพื่อคัดลอก

ขนาดแถว 912 ไบต์ตำแหน่งฟิลด์ = ที่อยู่แถว + offsetถาวร = -1 ใน effectEndurance

ชนิดและ offset มาจากไฟล์นิยามของ Paramdex ใช้ได้กับ 343 ฟิลด์แรก ฟิลด์ท้ายตารางบางตัว (เช่น isHpBurnEffect) ชื่อใหม่กว่าไฟล์นิยามที่ผมมี จึงยังไม่ระบุ offset ความหมายภาษาไทยเป็นการแปลของผมจากคำอธิบายภาษาญี่ปุ่นในไฟล์นิยาม ถ้าตัวไหนไม่ชัวร์ให้เทียบกับ Smithbox อีกที
