> **Last Updated:** _2026-10-11_

**Summary:** **The text and the fire colour of a spell.** A spell now has a name, a short line and a long description in the game, written in the design as `"text": {"goods_name", "goods_info", "goods_captions"}` (replacing `name` and `description`), and the design can give the fire of *Flame, Grant Me Strength* a colour with `"flame_color": [r, g, b]`. `run` puts both into the running game by itself once a character is in the world (`write --text --when-loaded`, `write --flame-color --when-loaded`). Nothing is written to any file: the text tables are rebuilt in the game's memory and the game is pointed at them; the colour is written into the game's copy of the fire's effect files. Both find what they change by looking through the game's memory with one shared, game-friendly scan; no fixed address from the exe is used.

## Measured (real game, 2026-10-11, three `run` sessions)

Text (first design, 16 MB pieces, measured): the three tables found in 0.6-0.7 s, the array in a look through all the memory (70-73 s), written and read back about 75 s after the character is in the world. Fire: both effects found in 6.4-6.6 s, 68 places written and read back, about 7 s after the character is in the world.

## Migration

Move the words of a spell into `text`: `name` → `text.goods_name`, `description` → `text.goods_info` (short) and/or `text.goods_captions` (long). A secured build stays valid: neither the text nor the colour is part of it. To write a spell in the structure of section 1b, move `requires` into `requires.status`, `fp_cost` / `stamina_cost` into `requires.cost.focus_point` / `.stamina`, `shop` into `locations.kale`, `set` into `customs.basic`, `text` into `customs.advanced.texts` (`goods_captions` may be named `goods_caption`), `flame_color` (+ `flame_accent_color`) into `customs.advanced.colors."Magic.<from>.castSfxId"` (`[r, g, b]` or `{"main", "accent"}`) and `positive_curse_energy_eyes` into `customs.advanced.colors."<on>"`; nothing has to be moved, and a secured build stays secured either way. A profile of another game version needs `text.files` and `text.sizes` (adding-a-profile).
